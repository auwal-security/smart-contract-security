# Smart Contract Security Research

Independent security research focused on Solidity, DeFi,
lending protocols, vaults, and protocol accounting.

## Security Research Focus

• DeFi accounting
• Lending & liquidation mechanisms
• Vaults / ERC-4626
• State-transition vulnerabilities
• Economic attacks
• Oracle mechanisms
• Access control

## Methodology

I approach protocol security by first understanding the
intended invariants and economic assumptions, then
constructing adversarial transaction sequences to
determine whether those assumptions can be violated.

I prioritize reproducible Proofs of Concept and
demonstrable security impact over purely theoretical
code smells.
